WebAwesome extension for the HTML UI builder
=============================================

This package extends the [HTML UI builder](https://github.com/lagdo/ui-builder) and implements functions to create UI components for WebAwesome.

### Usage

Create a builder instance.

```php
use Lagdo\UiBuilder\WebAwesome\Builder;

$builder = new Builder();
```

See the [HTML UI builder](https://github.com/lagdo/ui-builder) documentation.
